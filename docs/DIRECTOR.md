# Playhouse director acceptance

Status: BUILDING. The complete user journey is the acceptance test.

Promise: Anyone can challenge a real Chog Genesis NFT as an evolving arcade boss. The NFT's identity and traits set its behavior. Results and history persist per token. The current holder can change bounded boss settings.

Player journey: open app without wallet; choose a mainnet Genesis NFT; play a genuine 45-second fight; see accurate result; refresh and see updated boss history; rematch.

Holder journey: connect wallet; sign in; choose owned token; save permitted attack setting; see it affect next fight. Nonowner writes fail. Transfer revokes old owner's control.

Must be real: Monad mainnet contract, tokenURI/metadata/ownership, game mechanics, durable history, backend owner authorization. Controlled NFTs and local chain simulations test owner logic but do not prove a Genesis holder completed production owner flow.

Gates: live metadata proof; complete public vertical slice; fresh browser deployed UAT; owner/nonowner/transfer tests; truthful errors and refresh recovery; accurate README and submission claims.

NOW: one arena, three readable attack families, 45-second round, result/history/rematch, bounded holder control. NEXT: additional arenas and stronger leaderboard validation. LATER: tournaments, rewards, economy.

Stop if core live metadata cannot be made to load in the deployed app, if ownership checks fail, or if the deployed public journey cannot finish. Never call the project complete based only on tests or a 200 response.
